# NVDA checklist (manual, about 15 minutes)

For the owner, on Windows with NVDA (free, nvaccess.org) and the desktop app. Use the default settings: browse mode switches on by itself in documents, and Insert+Space toggles focus/browse mode. Tick each line and note anything that is not said, or is said twice.

## Start and shell
- [ ] Launch while signed in. With the restart cache, the last channel shows at once. The composer area says "Connecting… You can send messages once Vokko is back online." (a status), and it goes away when READY arrives.
- [ ] Insert+F7 → Landmarks lists "Servers sidebar" (navigation), main, "Members" (complementary) and "User status and settings".
- [ ] Tab from the top: the server rail, then the channel list, the chat header, the message list ("Messages in #channel"), the composer, then the member list. No stop is silent and none goes without a visible ring.

## Chat
- [ ] Have a second account send a message to the open channel: NVDA says "Name: text" once, without moving focus. Your own messages are not read out.
- [ ] Busy channel (several messages in a few seconds): each one is read and nothing repeats. Note it if this is too chatty.
- [ ] Ctrl+K: "Quick switcher" dialog, the combobox is announced, arrows read each result, Enter opens it, Esc returns to where you were.
- [ ] Shift+F10 on a message (or the Applications key): the menu opens with focus inside, arrows read the items, Esc returns focus.
- [ ] Up in an empty composer edits your last message; Esc cancels.

## Popouts and dialogs
- [ ] Click the server name: the menu takes focus and Esc returns it to the server name.
- [ ] Open a member's profile card from the member list: focus moves into it and Tab stays inside.
- [ ] User Settings: the dialog name is read, the sidebar marks the current page ("current"), and Esc returns focus to the User Settings button.
- [ ] Settings > Privacy: the "Send crash reports" switch reads its state (on/off) and toggles with Space.

## Voice
- [ ] Join a voice channel: the call controls ("Mute microphone", "Leave voice channel", and so on) each read a name and state. Known: the selected voice channel row nests buttons inside a button (A11Y-21), so NVDA may read the row and its actions as one item.

Report findings with the screen, what NVDA said, and what you expected.
